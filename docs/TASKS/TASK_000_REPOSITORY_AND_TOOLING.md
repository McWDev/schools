# Task 000 — Repository, Tooling, and Environment Baseline

## Objective
Create a reproducible development baseline before building application features.

## Scope
- Confirm Node.js LTS, npm, Git, editor, and chosen package manager.
- Initialize Next.js with TypeScript and App Router.
- Enable strict TypeScript, linting, formatting, and environment variable validation.
- Add a short architecture README and documented scripts.
- Create a clean initial Git commit.

## Acceptance criteria
- [ ] App starts locally using the documented command.
- [ ] TypeScript check passes.
- [ ] Lint passes.
- [ ] Production build passes.
- [ ] `.env*` secrets are ignored by Git; an `.env.example` contains placeholders only.
- [ ] No real credentials are committed.

## Tests / evidence
Share Node/npm versions, install output, lint/typecheck/build output, and the initial page screenshot. Do not proceed if setup errors remain unresolved.
