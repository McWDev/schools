# Task 006 — Branch/Campus Management

## Objective
Let school-wide administrators create and manage sub-branches.

## Scope
- Create, edit, view, deactivate branches.
- Branch code unique within a school.
- Assign administrators and staff to branch scope.
- Branch selector reflects only authorized branches.
- Preserve historical records when a branch is deactivated.

## Acceptance criteria
- [ ] Only authorized school-level users create/deactivate branches.
- [ ] Branches always belong to the correct school.
- [ ] School-wide admin sees all branches for that school.
- [ ] Branch staff see only assigned branches.
- [ ] Deactivation does not delete historical data.
