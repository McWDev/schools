# Task 007 — Academic Year, Terms, Grades, Classes, and Sections

## Objective
Create the academic structure that later modules depend on.

## Scope
Academic years, terms/semesters, grade levels, classes, sections, capacity, and active status. Each record is school-scoped and branch-scoped where appropriate.

## Acceptance criteria
- [ ] School admins can configure their school's academic structure.
- [ ] Branch users operate only in authorized branches.
- [ ] Duplicate codes/names are handled according to documented scope.
- [ ] Historical academic structures are deactivated, not destructively removed.
