# Task 009 — Staff and Teacher Records

## Objective
Manage employee/teacher profiles, employment status, and branch assignments.

## Scope
Profile, staff number, role/title, qualifications, employment status, assigned branches, and subject/class assignments as permitted. Sensitive HR fields require stricter permissions.

## Acceptance criteria
- [ ] School and branch scope is enforced.
- [ ] Staff cannot edit their own privileged access.
- [ ] Employment termination/deactivation blocks system access as configured while retaining historical academic/audit records.
- [ ] Sensitive HR data is not returned to unauthorized roles.
