# Task 010 — Subjects, Class Assignments, and Timetables

## Objective
Manage subjects and assign teachers/classes/periods.

## Scope
Subjects, class-subject mappings, teacher assignments, room/period timetable, conflict detection, and branch-specific schedules.

## Acceptance criteria
- [ ] Assignments cannot reference another school's records.
- [ ] Timetable conflicts are detected according to agreed rules.
- [ ] Teachers see only their authorized classes and subjects.
- [ ] Changes preserve a useful history where needed.
