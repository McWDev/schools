# Task 011 — Attendance

## Objective
Record and report student attendance.

## Scope
Attendance sessions by the chosen policy (daily, period-based, or both), present/absent/late/excused statuses, authorized corrections, summaries, and audit events.

## Acceptance criteria
- [ ] Only authorized users mark attendance for assigned classes/branches.
- [ ] Duplicate attendance for the same student/session is prevented.
- [ ] Corrections preserve who changed what and when.
- [ ] Reports obey school and branch scope.
