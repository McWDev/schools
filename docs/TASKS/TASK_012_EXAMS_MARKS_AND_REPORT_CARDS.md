# Task 012 — Exams, Marks, Grading, and Report Cards

## Objective
Support exam schedules, mark entry, grading, review, and report cards.

## Scope
Exam setup, subject/assessment components, marks, grading scale, result review/approval if configured, report-card generation, and controlled exports.

## Acceptance criteria
- [ ] Grading and rounding rules are documented before implementation.
- [ ] Marks are validated against configured maximums.
- [ ] Unauthorized users cannot change approved results.
- [ ] Changes to official marks are audited.
- [ ] Report cards include only authorized student data.
- [ ] Cross-branch access tests pass.
