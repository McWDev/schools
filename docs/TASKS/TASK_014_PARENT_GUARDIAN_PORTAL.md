# Task 014 — Parent/Guardian Portal and Communications

## Objective
Allow verified guardians to access permitted information about linked children.

## Scope
Guardian identity, child relationship verification, access revocation, announcements, and permitted attendance/results/fees views.

## Acceptance criteria
- [ ] Guardians can access only verified linked children.
- [ ] Forged student IDs do not bypass relationship checks.
- [ ] Sensitive school notes are excluded unless explicitly authorized.
- [ ] Revoked relationships lose access promptly.
