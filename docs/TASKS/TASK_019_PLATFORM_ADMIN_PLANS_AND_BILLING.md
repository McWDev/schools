# Task 019 — SaaS Super Admin, Plans, Quotas, and Billing Integration

## Objective
Operate the SaaS platform and enforce plan-based limits.

## Scope
Tenant lifecycle management, plans, feature flags, quotas, usage summaries, operational support controls, and optional subscription billing provider integration.

## Acceptance criteria
- [ ] Platform controls are separate from school administration.
- [ ] Platform admin access is protected by MFA where supported.
- [ ] Support access to school data is exceptional, approved, time-limited, and audited.
- [ ] Plan/feature/limit checks are enforced server-side.
- [ ] Billing provider webhooks are authenticated, idempotent, and audited.
